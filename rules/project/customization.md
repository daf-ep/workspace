# Customize Global Preferences

This file is different from the other files in `.claude/injectable/`: it repeats nothing from a specific `common/` subject, because none talks about it. It gathers preferences that apply to all the work on this project rather than to a single subject.

Adding a rule for this project is all it takes to adapt it, without touching the rest of the list.

## Global Rules to Follow

- Conversation language: no rule imposed, the conversation follows the language of whoever is writing.
